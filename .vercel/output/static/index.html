// selected projects
orderbook-engine
A single-threaded matching engine in C++17 implementing price-time priority for bids and asks. The interesting part is the documented optimization arc — seven iterations from a naive std::map baseline down to ~51 ns median latency using occupancy bitsets and hardware bit-scan instructions.
